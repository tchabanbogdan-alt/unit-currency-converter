# Конвертер валют і одиниць виміру

Навчальний проєкт з дисципліни «Програмування веб-застосувань»
(2 курс, ФІОТ, КПІ ім. Ігоря Сікорського).

**Варіант:** 6 — Конвертер валют і одиниць виміру
**Робоча назва проєкту:** unit-currency-converter

## Опис

Клієнтський застосунок для переведення значень між валютами
та одиницями виміру (довжина, вага).

## Заплановані розділи сторінки

1. Шапка з назвою застосунку
2. Блок вибору типу конвертації (валюта / довжина / вага)
3. Форма введення значення й одиниць
4. Блок результату
5. Підвал
